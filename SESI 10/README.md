# NusaKantin

NusaKantin adalah aplikasi pemesanan makanan
kantin kampus berbasis Flutter dengan desain
responsif untuk HP dan tablet.

## Fitur Aplikasi

1. Menampilkan daftar menu makanan.
2. Filter menu berdasarkan kategori.
3. Melihat detail makanan.
4. Menambahkan makanan ke pesanan.
5. Mengurangi jumlah pesanan.
6. Menghitung total harga.
7. Tampilan responsif HP dan tablet.

## Teknologi

- Flutter
- Dart
- Provider
- Material Design 3

## Menjalankan Aplikasi

flutter pub get

flutter run

## Menjalankan Widget Test

flutter test
